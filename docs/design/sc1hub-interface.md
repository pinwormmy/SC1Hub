# SC1Hub interface

- 공략 탐색은 내 종족 → 상대 종족 → 개별 공략 순서로 구성한다.
- SC1Hub 명칭과 기존 파비콘을 사용하며, 저장소 경로·공개 저장소 배지·타사 서비스 로고를 UI 장식으로 사용하지 않는다.
- 공통 스타일은 `src/main/resources/static/css/sc1hub-theme.css`에서 관리한다. 개발자 사이트풍 시각 언어(2026-09-13): 중립 회색 표면(밝음 #ffffff/#f6f8fa, 어두움 #0d1117/#161b22), 1px 테두리 6px 라운드 "박스" 패널과 회색 헤더 띠, 파란 텍스트 링크(#0969da)와 초록 주 버튼(#1f883d), 상단 밑줄 탭 내비(주황 밑줄), 시스템 폰트 14px. 종족색은 테란=파랑, 저그=보라, 프로토스=호박색 점으로만 표시한다.
- 색은 전부 `--sc-*` 토큰으로만 쓰고 hex를 직접 박지 않는다. 관리자 페이지 인라인 스타일도 같은 토큰을 쓴다.
- 스타일과 테마 동작은 프로젝트 내에서 작성했다. 이 UI 작업으로 외부 CSS 프레임워크, 아이콘 패키지, 이미지 또는 웹폰트를 추가하지 않았다. 기존 자산과 게시물 콘텐츠의 권리 확인은 별도 범위다.
- `site-theme.js`는 저장된 `sc1hub.theme` 설정을 우선 적용한다. 설정이 없으면 기기 설정을 따르고, 화면이 처음 그려지기 전에 테마를 적용한다.
- 공략 게시물 번호에 연결된 `data-menu-number`와 기존 이동 기능을 유지한다. 새 상대 종족별 제목은 해당 게시판으로 연결한다.
- UI 검증은 운영 DB와 연결하지 않는 로컬 JSP 미리보기에서 수행한다. 배포 전에는 전체 빌드와 PC·모바일 스크린샷을 확인한다.
